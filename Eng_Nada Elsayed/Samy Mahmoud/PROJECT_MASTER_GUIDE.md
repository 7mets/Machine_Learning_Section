## 1. مقدمة وفكرة المشروع

### ما هي المشكلة؟
شركة توزيع تجارية تبيع منتجاتها لـ **440 عميلاً تجارياً** (مثل المطاعم، الفنادق، محلات البقالة، السوبرماركت).
معاملة جميع العملاء بنفس العروض والأسعار وجداول التوصيل يؤدي إلى خسائر مالية وتكدس في المخزون وعدم رضا العملاء.

### ما هو الحل؟
بناء مسار تعلم آلي غير خاضع للإشراف (**Unsupervised Machine Learning**) يعتمد على خوارزمية **K-Means Clustering**:
* يقوم بتحليل مبالغ الإنفاق السنوي لكل عميل دون الحاجة لتصنيفات مسبقة.
* يقسم العملاء تلقائياً إلى مجموعات متجانسة تشترك في نفس السلوك الشرائي.
* يقدم توصيات عملية لكل شريحة (عروض أسعار، جداول توريد، وتسهيلات دفع).

## 3. المعالجة المسبقة وحل مشكلة الالتواء الإحصائي

### لماذا لا يمكن تشغيل K-Means مباشرة على البيانات الخام؟
1. **الالتواء الشديد (Severe Right Skewness):**  
   معظم العملاء إنفاقهم متوسط، بينما قلة قليلة من كبار المشترين ينفقون مبالغ خرافية (الالتواء في Delicassen يصل لـ **+11.15**).
2. **فروق المقاييس والمسافة الإقليدية:**  
   خوارزمية K-Means تقيس المسافات بين النقاط بالمسافة الإقليدية:
   $$d(x, y) = \sqrt{\sum_{j=1}^d (x_j - y_j)^2}$$
   القيم الكبيرة في فئة Fresh (12 ألف) ستهيمن تماماً على حساب المسافات بنسبة تزيد عن 98%، وتلغي تأثير فئات مثل Delicassen (1.5 ألف).

### الحل المطبق:
1. **التحويل اللوغاريتمي:** $x_{log} = \ln(1 + x)$ لتقليص ذيول التوزيع اليمينية وإعادة البيانات لتوزيع شبه طبيعي متماثل (انخفض الالتواء من 11.15 إلى -1.09).
2. **التسوية القياسية (`StandardScaler`):** $z = \frac{x - \mu}{\sigma}$ لتصبح جميع المتغيرات ممركزة عند الصفر بانحراف معياري يساوي 1، مما يضمن وزناً متساوياً لجميع الفئات.

## 4. الأساس الرياضي لخوارزمية K-Means

تتبع الخوارزمية طريقة **Lloyd's Algorithm** بخمس خطوات رئيسية:
1. **تحديد K:** اختيار عدد المجموعات مسبقاً.
2. **التهيئة الذكية (K-Means++):** اختيار مراكز البداية باحتمالية تتناسب مع مربع البعد $D(x)^2$ لتوزيع المراكز بعيداً عن بعضها ومنع الوقوع في أدنى محلي سيء (*Local Minimum*).
3. **خطوة التعيين (Assignment):** تعيين كل نقطة $x$ لأقرب مركز $\mu_k$:
   $$c(x) = \arg\min_k \|x - \mu_k\|^2$$
4. **خطوة التحديث (Update):** نقل مركز المجموعة إلى المتوسط الحسابي لنقاطها:
   $$\mu_k = \frac{1}{|C_k|} \sum_{x \in C_k} x$$
5. **التكرار (Repeat):** تكرار الخطوتين 3 و 4 حتى ثبات المراكز وعدم انتقال أي نقطة لمجموعة أخرى.

* **دليل التقارب:** في كل خطوة، دالة الهدف (القصور الذاتي $J$) تنخفض أو تثبت ولا تزيد أبداً:
  $$J = \sum_{k=1}^K \sum_{x \in C_k} \|x - \mu_k\|^2$$
  ولأن عدد طرق تقسيم النقاط محدود، فالخوارزمية مضمونة التقارب والوصول للحل النهائي.

## 5. تحديد العدد الأمثل للمجموعات K

قمنا باختبار قيم $K$ من 2 إلى 8 مع 20 تكرار لكل قيمة:

| عدد المجموعات ($K$) | Inertia (WCSS) | Silhouette Score | Davies-Bouldin | Calinski-Harabasz |
| :---: | :---: | :---: | :---: | :---: |
| **K = 2** | 1844.1 | 0.2903 | 1.352 | 189.0 |
| **K = 3** | **1553.4** | **0.2583** | **1.348 (الأفضل)** | 152.8 |
| **K = 4** | 1386.9 | 0.1885 | 1.541 | 131.3 |
| **K = 5** | 1266.1 | 0.1916 | 1.484 | 118.0 |
| **K = 6** | 1174.5 | 0.1953 | 1.414 | 108.3 |
| **K = 7** | 1086.4 | 0.1958 | 1.392 | 103.2 |
| **K = 8** | 1024.1 | 0.1915 | 1.385 | 97.4 |

### التبرير الرياضي والتجاري لاختيار $K = 3$:
1. يظهر منحنى القصور الذاتي نقطة "كوع" واضحة عند $K = 3$ يتباطأ بعدها معدل انخفاض التباين الداخلي.
2. حققت القيمة $K = 3$ أقل قيمة لمؤشر Davies-Bouldin (1.348) مما يدل على أقل تداخل ممكن بين المجموعات.
3. تجارياً: القيمة $K=3$ تفصل العملاء بوضوح إلى (محلات البقالة، المطاعم والضيافة، وكبار العملاء ذوي الإنفاق الضخم)، بينما $K=2$ تدمج كبار العملاء والمطاعم في مجموعة واحدة عامة تفقد قيمتها التطبيقية.

## 6. شرح كود بايثون سطر بسطر

```python
# 1. استيراد المكتبات الأساسية
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, davies_bouldin_score
from sklearn.decomposition import PCA

# 2. قراءة البيانات وفحص أبعادها
df = pd.read_csv('Wholesale customers data.csv')
spending_cols = ['Fresh', 'Milk', 'Grocery', 'Frozen', 'Detergents_Paper', 'Delicassen']

# 3. التحويل اللوغاريتمي والتسوية القياسية
df_log = np.log1p(df[spending_cols])
scaler = StandardScaler()
X_scaled = scaler.fit_transform(df_log)

# 4. تدريب النموذج الأمثل بـ K=3 مع K-Means++
km = KMeans(n_clusters=3, init='k-means++', n_init=30, random_state=42)
df['Cluster'] = km.fit_predict(X_scaled)

# 5. حساب متوسطات الإنفاق ونسب الشراء لكل شريحة
cluster_means = df.groupby('Cluster')[spending_cols].mean()
relative_spending = cluster_means.div(df[spending_cols].mean(), axis=1)

# 6. تمثيل النتائج ثنائياً بواسطة PCA
pca = PCA(n_components=2, random_state=42)
X_pca = pca.fit_transform(X_scaled)
df['PCA1'] = X_pca[:, 0]
df['PCA2'] = X_pca[:, 1]
```
